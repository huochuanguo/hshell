# HShell 0.3.1

面向 Ubuntu 22.04 / 24.04 的轻量 SSH 原生客户端（amd64）。

- 支持连接管理、多标签终端、系统凭据库保存密码。
- SFTP 支持上传、下载、双向断点续传、暂停及重启后恢复。
- 文件栏区分目录、链接、代码、压缩包及图片，目录使用柔金色名称和图标，链接使用青绿色，其他文件名保持浅灰。
- 六类图标缓存复用，分类不增加远程请求，文件内容不经过界面线程。

下载 `hshell_0.3.1_amd64.deb` 及同名 `.sha256` 文件，放在同一目录。先验证校验值，再退出旧客户端并安装：

```bash
sha256sum --check hshell_0.3.1_amd64.deb.sha256
sudo apt install ./hshell_0.3.1_amd64.deb
```

保留既有连接配置、系统凭据及 OpenSSH 信任记录，无数据库迁移。正式包使用 Ubuntu 22.04 构建；自动发布须通过 Ubuntu 22.04 和 24.04 的实际安装、启动与关闭检查。

Windows 尚在适配预留阶段，本次不提供 Windows 安装包。目录同步、远程编辑及目录递归传输未包含。
