# HShell 0.3.9

修复终端执行 `ls --color` 时，部分权限高亮的目录名难以辨认的问题。所有用户可写的目录仍保留绿色背景，普通目录和带 sticky bit 的目录也能清楚区分。此更新只影响显示，不修改文件权限或远程 Shell 配置。

| 平台 | 安装包 |
| --- | --- |
| Windows 10 1809+ / Windows 11（x64） | `HShell_0.3.9_x64-setup.exe` |
| Ubuntu 22.04 / 24.04（amd64） | `hshell_0.3.9_amd64.deb` |

升级前请退出正在运行的 HShell。两个安装包均附带同名的 `.sha256` 校验文件。
