Windows 和 Ubuntu 统一为 0.3.16。

- 点击终端工具栏的「文件」，在主窗口内以独立的 SFTP 标签管理文件，不再占用终端右侧空间，也不会自动收起主机栏。
- 每个 SFTP 标签绑定打开它的 SSH 会话。切回标签会恢复当前目录、筛选条件和选中项；编辑已保存主机的账号或端口后，新旧会话不会混用文件浏览连接。
- 关闭文件标签后，已加入队列的传输仍会继续。可通过工具栏的传输入口查看并管理全局队列。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `HShell_0.3.16_x64-setup.exe` |
| Ubuntu amd64 | `hshell_0.3.16_amd64.deb` |

两个安装包均附带 SHA-256 校验文件。
