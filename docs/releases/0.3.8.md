# HShell 0.3.8

Windows 和 Ubuntu 使用统一的应用标识 `io.hshell.ssh`。工作空间信息显示新的连接配置路径：Windows 默认在 `%APPDATA%\io.hshell.ssh\profiles.json`，Ubuntu 默认在 `~/.config/io.hshell.ssh/profiles.json`。

| 平台 | 安装包 |
| --- | --- |
| Windows 10 1809+ / Windows 11（x64） | `HShell_0.3.8_x64-setup.exe` |
| Ubuntu 22.04 / 24.04（amd64） | `hshell_0.3.8_amd64.deb` |

升级前请退出旧版。在 Windows 安装程序中保留应用数据；曾自定义安装目录时，请确认安装位置。新版首次启动时会迁移连接、命令片段、SFTP 续传记录及 Windows 终端字号。新旧目录同时存在时，会使用新目录并保留旧目录。已保存的密码会在下次使用时迁移到新的系统凭据服务，无需导出或重新输入。

Ubuntu 下载 `.deb` 和同名的 `.sha256` 文件后，可先核对校验值再安装：

```bash
sha256sum --check hshell_0.3.8_amd64.deb.sha256
sudo apt install ./hshell_0.3.8_amd64.deb
```
