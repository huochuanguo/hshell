# HShell 0.3.7

Windows 与 Ubuntu 同步发布。请按操作系统选择安装包：

| 平台 | 安装包 |
| --- | --- |
| Windows 10 1809+ / Windows 11（x64） | `HShell_0.3.7_x64-setup.exe` |
| Ubuntu 22.04 / 24.04（amd64） | `hshell_0.3.7_amd64.deb` |

- SSH 终端支持 `Tab` 键和工具栏「Tab」按钮，由远端 Shell 补全命令或路径。
- SFTP 支持筛选当前目录、复制远端绝对路径、批量上传和下载，以及拖拽本地文件上传。批量下载跳过已有的同名文件。
- 命令片段可按分组保存和搜索，插入终端后需按 Enter 执行。
- 可用 JSON 在两端迁移连接配置；备份不包含密码、私钥及私钥路径，导入时跳过重复连接。
- SSH 连接失败时，在保留原始输出的同时提供常见问题的中文排查提示。

升级前请退出正在运行的 HShell。Windows 直接运行安装程序；Ubuntu 将 `.deb` 与同名 `.sha256` 下载到同一目录，再执行：

```bash
sha256sum --check hshell_0.3.7_amd64.deb.sha256
sudo apt install ./hshell_0.3.7_amd64.deb
```
