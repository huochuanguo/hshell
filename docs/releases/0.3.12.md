Windows 和 Ubuntu 统一为 0.3.12。

- SFTP 点一次「上传」即打开本地选择窗口，可混选文件和文件夹并一次提交，也可把文件和文件夹一起拖到远程文件列表。
- Windows 上传选择窗口采用文件管理器布局：左侧点选盘符，右侧按名称和类型浏览本地项目。在盘符根目录点「上一级」可返回「此电脑」。浏览长目录时，路径栏和列标题保持可见。
- Windows 选择单个文件后按原名上传，省去额外的命名步骤。同名文件仍会在覆盖前确认。
- Windows 文件栏在没有传输任务时收紧队列高度，为远程文件列表留出更多空间。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `HShell_0.3.12_x64-setup.exe` |
| Ubuntu amd64 | `hshell_0.3.12_amd64.deb` |

两个安装包均附带 SHA-256 校验文件。
