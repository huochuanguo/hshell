# HShell 0.3.4

面向 Ubuntu 22.04 / 24.04 的轻量 SSH 原生客户端（amd64）。

- 保留文件类型配色、多标签终端、系统凭据保存与 SFTP 双向断点续传、暂停及重启后恢复。
- 接入 GitHub 自动构建、传输验证、双系统安装检查与发行版附件上传。
- 修复验证探针在 SSH 启动较慢时提前暂停、退出的问题：先确认真实断点落盘，再验证中断与恢复；发布测试注入 2 秒启动延迟回归。
- 断网恢复测试同样以已持久保存的断点为触发条件，并确认超时后仍有非零断点，避免连接耗时影响测试。
- 大文件传输等待与界面响应验收分别计时，输入 100 ms、滚动及目录调度 50 ms 的 P95 门槛保持不变。测试探针不进入正式安装包。
- Ubuntu 22.04、24.04 与发布任务使用独立编译缓存。
- 修复 Windows 构建检查中 Unix 测试导入缺少平台条件的问题。

下载 `hshell_0.3.4_amd64.deb` 及同名 `.sha256` 文件，放在同一目录：

```bash
sha256sum --check hshell_0.3.4_amd64.deb.sha256
sudo apt install ./hshell_0.3.4_amd64.deb
```

安装前退出旧客户端。连接配置、系统凭据及 OpenSSH 信任记录继续使用，无数据库迁移。安装包在 Ubuntu 22.04 构建，通过 SFTP 中断恢复与校验，以及 Ubuntu 22.04/24.04 实际安装、启动与关闭检查后才发布。

Windows 尚在适配预留阶段，本次不提供 Windows 安装包。目录同步、远程编辑及目录递归传输未包含。
