# HShell 0.3.5（Ubuntu）

适用于 Ubuntu 22.04 / 24.04（amd64）。

- 同步 Windows 适配期间的共享 SSH/SFTP 核心改动。传输和重启续传统一按 Unix 路径规则处理远端文件，并校验断点记录中的临时文件路径。
- Ubuntu 继续使用 GTK 和 VTE 原生终端，现有连接配置、系统凭据与 OpenSSH 信任记录无需迁移。

下载 `hshell_0.3.5_amd64.deb` 与同名 `.sha256` 文件并放在同一目录。退出正在运行的客户端，再执行：

```bash
sha256sum --check hshell_0.3.5_amd64.deb.sha256
sudo apt install ./hshell_0.3.5_amd64.deb
```

正式安装包在 Ubuntu 22.04 构建，通过 SFTP 续传验证及 Ubuntu 22.04、24.04 的安装和启动检查后发布。
