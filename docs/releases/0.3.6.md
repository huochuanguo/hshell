# HShell 0.3.6

Ubuntu 和 Windows 现使用同一个版本号。请按系统选择安装包：

| 平台 | 安装包 |
| --- | --- |
| Windows 10 1809+ / Windows 11（x64） | `HShell_0.3.6_x64-setup.exe` |
| Ubuntu 22.04 / 24.04（amd64） | `hshell_0.3.6_amd64.deb` |

- Windows：终端字号可调整；修复末行文字、光标被截断及底部露出纯黑条的问题。安装包未做代码签名。
- Ubuntu：更新共享 SSH/SFTP 核心，保留 GTK/VTE 原生终端。文件传输和续传使用 Unix 远程路径规则，并校验断点记录中的临时文件路径。

升级前请退出 HShell。原有连接配置、系统凭据及 OpenSSH 信任记录无需迁移。两个安装包均附有同名 `.sha256` 校验文件。

Ubuntu 下载 `.deb` 和 `.deb.sha256` 到同一目录后，可以这样校验和安装：

```bash
sha256sum --check hshell_0.3.6_amd64.deb.sha256
sudo apt install ./hshell_0.3.6_amd64.deb
```
