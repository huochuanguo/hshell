# HShell 0.3.2

面向 Ubuntu 22.04 / 24.04 的轻量 SSH 原生客户端（amd64）。

- 保留 0.3.1 的文件类型配色：目录柔金、链接青绿，代码、压缩包及图片使用不同图标颜色，普通文件名保持浅灰。
- 保留多标签终端、系统凭据保存与 SFTP 双向断点续传、暂停及重启后恢复。
- 接入 GitHub 自动构建、传输验证、双系统安装检查与发行版附件上传。
- 修复云端验证脚本对大文件传输完成时间的过短等待；终端输入与滚动的响应阈值保持不变。探针仅用于测试，不进入正式安装包。

下载 `hshell_0.3.2_amd64.deb` 及同名 `.sha256` 文件，放在同一目录：

```bash
sha256sum --check hshell_0.3.2_amd64.deb.sha256
sudo apt install ./hshell_0.3.2_amd64.deb
```

安装前退出旧客户端。连接配置、系统凭据及 OpenSSH 信任记录继续使用，无数据库迁移。安装包在 Ubuntu 22.04 构建，并通过 Ubuntu 22.04/24.04 的实际安装、启动与关闭检查后才发布。

Windows 尚在适配预留阶段，本次不提供 Windows 安装包。目录同步、远程编辑及目录递归传输未包含。
