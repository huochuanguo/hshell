Windows 和 Ubuntu 统一为 0.3.13。

- Windows 主机列表单击选中，双击或按 Enter 连接，与 Ubuntu 一致。
- Windows 可拖动终端和文件栏之间的分隔条调整宽度，终端会同步重排。聚焦分隔条后也可用左右方向键调整。
- 两端 SFTP 文件列表统一显示名称、类型、大小、修改时间和权限。窄栏优先保留文件名；悬停可查看完整信息。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `HShell_0.3.13_x64-setup.exe` |
| Ubuntu amd64 | `hshell_0.3.13_amd64.deb` |

两个安装包均附带 SHA-256 校验文件。
